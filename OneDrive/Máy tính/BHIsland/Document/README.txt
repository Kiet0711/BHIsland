GIsland Technical Blueprint – bộ tài liệu bàn giao

1. GIsland-Technical-Blueprint.docx
   Bản Word có thể chỉnh sửa: SRS, kiến trúc, ERD Mermaid, API overview,
   bảo mật, testing, tiêu chí nghiệm thu và roadmap 16 tuần.

2. GIsland-Technical-Blueprint.md
   Bản nguồn Markdown đầy đủ, thuận tiện chỉnh sửa trong Git/VS Code.

3. GIsland-OpenAPI.yaml
   Hợp đồng API OpenAPI 3.1 cho các endpoint cốt lõi của MVP.

4. GIsland-PostgreSQL-Core.sql
   Schema PostgreSQL tham chiếu cho các thực thể cốt lõi; cần đưa vào
   migration có version và rà soát theo implementation trước deploy.

Phạm vi công nghệ: SvelteKit + Node.js + PostgreSQL; web responsive;
mọi loại phương tiện. Roadmap giả định một người full-stack trong 16 tuần.
